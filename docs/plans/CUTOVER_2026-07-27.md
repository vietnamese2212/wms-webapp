## C. Trình tự thực hiện

1. Chạy `node scripts/qa/run-all.mjs` trên staging → **phải XANH toàn bộ** (cổng cứng, CLAUDE.md).
2. **User nghiệm thu trên Preview** (bắt buộc trước khi merge — không bỏ qua).
3. Backup production (Supabase Dashboard → snapshot) — bắt buộc vì có (7)(10)(11) đụng dữ liệu.
4. Apply nhóm 1 → 2 → 3 → 4 theo đúng thứ tự trên, qua Supabase Dashboard SQL Editor của
   **project production** (`svicyfquresxaigfxsdb`). Đọc output gác của từng file.
5. Merge `dev` → `main` (Vercel tự deploy production). Với (10) và (11): apply xong deploy NGAY.
6. Smoke production sau deploy: Tồn kho (lọc theo từng kho), Nhập kho, Xuất kho, Kiểm kê,
   In tem, ô chọn Mã hàng (gõ KHÔNG dấu), Cài đặt WMS → Khu vực (multi Loại kho).
7. Nếu hỏng: rollback code = revert commit merge trên `main`; rollback dữ liệu = bảng backup
   `x_bak_*` / snapshot ở bước 3.
